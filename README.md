# Publicações da Tema Consultoria em Gestão Pública

Textos publicados em https://consultoriatema.com.br/publicacoes/ e https://consultoriatema.com.br/boletim/.
O servidor da Tema lê este repositório a cada 10 minutos e atualiza o site sozinho.
O histórico de commits registra a data de cada publicação.

## Pastas

| Pasta | Conteúdo | Nome do arquivo |
|---|---|---|
| `artigos/` | um arquivo por artigo | `AAAA-MM-DD-titulo-curto.md` (minúsculas, sem acento, palavras separadas por hífen) |
| `boletins/` | uma edição por semana | número com 3 dígitos: `001.md`, `002.md`… |
| `autores/` | apresentação de cada autor | `diogo-muniz.md` |

O formato completo (cabeçalho, seções, regras de redação) está em [MODELO.md](MODELO.md).

Só aparece no site o texto com `data` até o dia de hoje. Dá para deixar um texto pronto com data futura: ele entra no ar sozinho no dia.
Para tirar um texto do ar sem apagá-lo, ponha `rascunho: sim` no cabeçalho.
